# ChainGPT NFT Generator - QuickStart Guide

## 🚀 Installation Complete!

The ChainGPT AI NFT Generator has been successfully integrated into Omega Terminal.

## ⚡ Quick Setup (2 Steps)

### Step 1: Get API Key
1. Visit https://api.chaingpt.org
2. Create an account
3. Generate an API key
4. Purchase credits (or use free trial)

### Step 2: Initialize in Terminal
```bash
nft init <your-api-key>
```

## 🎨 Your First NFT Generation

```bash
# Generate an AI NFT
nft generate "cyberpunk city at night"

# With custom style
nft generate "magical forest" --style=fantasy-art

# Enhance your prompt first
nft enhance "dragon warrior"
# Then use the enhanced version
nft generate "<enhanced-prompt-here>"
```

## 📚 Commands Available

| Command | Description |
|---------|-------------|
| `nft init <key>` | Set up API key |
| `nft generate "<prompt>"` | Create AI NFT |
| `nft enhance "<prompt>"` | Improve prompt |
| `nft models` | List AI models |
| `nft styles` | List art styles |
| `nft mint <id>` | Mint NFT on-chain |
| `nft chains` | Show blockchains |
| `nft status` | Check API status |
| `nft help` | Full documentation |

## ✨ Example Workflow

```bash
# 1. Initialize (first time only)
nft init sk_chaingpt_your_key_here

# 2. Check available models
nft models

# 3. Enhance your idea
nft enhance "cool robot"

# 4. Generate with style
nft generate "futuristic combat robot with neon lights" --style=neon-punk

# 5. Generate premium version
nft generate "same prompt" --model=Dale3 --enhance

# 6. Mint your favorite
nft mint <collection-id-from-step-4>
```

## 🎭 Popular Styles

- `fantasy-art` - Fantasy illustrations

## ⚠️ Troubleshooting

**"Not initialized" error:**
```bash
nft init <your-api-key>
```

**"Insufficient credits" error:**
- Visit https://api.chaingpt.org
- Purchase more credits

**Poor image quality:**
```bash
# Use enhancement
nft generate "prompt" --enhance

# Or use premium model
nft generate "prompt" --model=Dale3
```
