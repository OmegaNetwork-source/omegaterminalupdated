# 🎥 YouTube Player - Quick Start Guide

## Get Started in 3 Steps

### Step 1: Open YouTube Player
```bash
youtube open
```

### Step 2: Search for Videos
```bash
youtube search lofi hip hop
```

### Step 3: Watch!
Click any video thumbnail in the results to start watching.

---

## Essential Commands

### Open & Close
```bash
youtube open       # Open player
youtube close      # Close player
```

### Search & Play
```bash
youtube search <query>           # Search for videos
youtube search crypto news       # Example
youtube search coding music      # Example
youtube play <video-id>          # Play specific video
```

### Playback Controls
```bash
youtube pause      # Pause video
youtube next       # Next video in playlist
youtube prev       # Previous video
youtube mute       # Mute audio
youtube unmute     # Unmute audio
```

### Help
```bash
youtube help       # Show all commands
yt help           # 'yt' also works!
```

## Tips

### 💡 Tip 1: Automatic Playlist
When you search, all results become a playlist. Just click one video and use `youtube next` to watch them all!

### 💡 Tip 2: Background Watching
The player stays in the sidebar. You can run other terminal commands while watching!

### 💡 Tip 3: Theme Matching
Try the Executive theme for a gold YouTube player:
```bash
theme executive
youtube open
```

### 💡 Tip 4: Quick Access
Use `yt` as shortcut:
```bash
yt open
yt search coding
```

## Troubleshooting

### Player Not Opening?
```bash
# Hard refresh
Ctrl+Shift+R (Windows/Linux)
Cmd+Shift+R (Mac)

# Then try again
youtube open
```

### Search Not Working?
```bash
# Make sure panel is open first
youtube open

# Then search
youtube search your topic
```

### No Results?
- Check spelling
- Try different keywords
- Check internet connection
