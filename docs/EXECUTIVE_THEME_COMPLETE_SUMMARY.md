## 🚀 How to Activate

### For Users

**Simple Command**:
```bash
theme executive
```

**Full Experience**:
```bash
view futuristic    # Switch to dashboard view
theme executive    # Apply Executive theme
```

**Check Current Theme**:
```bash
theme
```

---

### For Developers

**JavaScript**:
```javascript
// Activate theme
OmegaThemes.setTheme('executive');

// Check if active
OmegaThemes.getCurrentTheme() === 'executive';

// Get theme info
OmegaThemes.getThemeDescriptions()['executive'];
```

**CSS Customization**:
```css
/* Override variables */
body.theme-executive {
    --exec-gold: #your-color;
    --exec-blue: #your-color;
}
```
