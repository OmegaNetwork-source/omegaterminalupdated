# 🚀 Executive Theme - Quick Start Guide

## Activate in 3 Steps

### Step 1: Open Terminal
Launch the Omega Terminal in your browser

### Step 2: Enter Command
```bash
theme executive
```

### Step 3: Enjoy!
You're now using the premium Executive Theme

## Quick Commands to Try

### Change Themes
```bash
theme executive    # Activate Executive theme
theme dark         # Back to dark theme
theme              # See current theme
```

### View All Themes
```bash
help theme
```

## Troubleshooting

### Theme Not Changing?
1. Try: `clear` then `theme executive`
2. Refresh the page
3. Clear browser cache

### Colors Look Different?
- Check display settings
- Verify browser color profile
- Try different browser

### Animations Choppy?
- Close other heavy tabs
- Update graphics drivers
- Check hardware acceleration is on
