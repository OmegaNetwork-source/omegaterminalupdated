## 🔧 **Command Functionality:**

### **Theme Commands:**
```bash
theme              # Show theme info
theme help         # Same as above
theme list         # Same as above
theme light        # Switch to light mode
theme dark         # Switch to dark mode
theme toggle       # Toggle between light/dark
```

### **GUI Commands:**
```bash
gui                # Show GUI styles info
gui help           # Same as above
gui chatgpt        # Transform to ChatGPT UI
gui discord        # Transform to Discord UI
gui aol            # Transform to AOL UI
gui windows95      # Transform to Windows 95 UI
gui limewire       # Transform to LimeWire UI
gui terminal       # Return to normal terminal
```

### **View Commands:**
```bash
view               # Show view info
view basic         # Switch to basic terminal
view futuristic    # Switch to dashboard
view toggle        # Toggle between views
```
