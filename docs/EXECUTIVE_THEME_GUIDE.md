# 🌟 Executive Theme - Premium Professional UI

## Overview

The **Executive Theme** is a premium, sophisticated UI theme designed for professional users who demand excellence in both form and function. This theme transforms the Omega Terminal into a luxurious command center with elegant gold accents, premium glass-morphism effects, and refined typography.

## 🎨 Design Philosophy

### Visual Identity
- **Premium Color Palette**: Sophisticated navy blues with luxurious gold accents
- **Glass Morphism**: Modern frosted glass effects with elegant blur
- **Professional Typography**: Premium fonts optimized for readability
- **Refined Animations**: Smooth, professional transitions that enhance UX
- **Depth & Shadow**: Carefully crafted shadows that create visual hierarchy

### Color Scheme
- **Primary**: Deep midnight blues (#0a0e27, #141b3d, #1e2649)
- **Accent**: Luxurious gold (#d4af37, #f4cf57)
- **Secondary**: Executive blue (#4a90e2)
- **Status Colors**: 
  - Success: Emerald (#50c878)
  - Error: Ruby (#e74c3c)
  - Warning: Amber (#f39c12)
  - Info: Sky Blue (#5fa8ff)

## 🚀 Quick Start

### Activating the Theme

#### Method 1: Command Line
```bash
theme executive
```

#### Method 2: Theme Toggle
Use the theme toggle button in the header to cycle through available themes until you reach Executive.

#### Method 3: Direct JavaScript
```javascript
OmegaThemes.setTheme('executive');
```

### Checking Current Theme
```bash
theme
```

## 🔧 Customization

### CSS Variables
All theme colors are defined as CSS variables and can be customized:

```css
:root.theme-executive {
    --exec-midnight: #0a0e27;
    --exec-gold: #d4af37;
    --exec-blue: #4a90e2;
    /* ... and more */
}
```

### Override Examples

#### Change Gold Accent
```css
body.theme-executive {
    --exec-gold: #ffd700; /* Your custom gold */
    --exec-gold-bright: #ffed4e;
}
```

#### Adjust Glass Blur
```css
body.theme-executive {
    --exec-glass-blur: blur(16px); /* Less blur */
}
```
