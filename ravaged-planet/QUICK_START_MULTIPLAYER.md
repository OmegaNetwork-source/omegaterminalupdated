# Quick Start: Multiplayer PVP

## Step 1: Start the Server

Open a terminal and run:
```bash
cd ravaged-planet
npm run server
```

You should see:
```
🚀 Multiplayer Server running on port 3001
📡 WebSocket endpoint: ws://localhost:3001
```

## Step 2: Start the Game

Open **another** terminal and run:
```bash
cd ravaged-planet
npm run dev
```

## Step 3: Play!

1. Open your browser to the URL shown (usually `http://localhost:5173`)
2. Click **"1V1 MULTIPLAYER"** in the menu
3. Enter your name
4. Click **"CONNECT"**
5. Click **"FIND OPPONENT"**
6. Wait for a match!
7. Play best-of-3 rounds!

## Testing Locally

To test with two players on the same machine:
1. Start the server (Step 1)
2. Start the game (Step 2)
3. Open **two different browser windows** (or use incognito mode)
4. Connect both and queue up
5. You'll be matched together!

Enjoy your retro tank battles! 🎮💥
